# tracespace browser bundles

Vendored browser bundles used by the repository file preview for Gerber and Excellon drill files.

Source:

- `pcb-stackup` 4.2.8 (`dist/pcb-stackup.min.js`)

The 4.2.x stack is used because it matches the public tracespace viewer and renders drill layers correctly for common Excellon files.
