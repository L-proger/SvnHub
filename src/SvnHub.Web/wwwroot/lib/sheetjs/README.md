# SheetJS Community Edition

This directory vendors the SheetJS CE 0.20.3 browser bundle and the official
SheetJS x-spreadsheet integration adapter used by the read-only spreadsheet
preview.

- Source: https://cdn.sheetjs.com/xlsx-0.20.3/package/
- Integration adapter: https://cdn.sheetjs.com/xspreadsheet/xlsxspread.js
- Integration documentation: https://docs.sheetjs.com/docs/demos/grid/xs/
